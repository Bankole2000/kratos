# AGENTS.md — packages/api-client-ts

These instructions add to the repository root `AGENTS.md`; they never relax it. Read the root file first.

## What this package is
- Purpose: the typed TypeScript client for the Platform Core API (`apps/api`), generated from `openapi/openapi.json`.
- Kind: API contract
- Used by: ui (`packages/ui`) now, and through it web (`apps/web`) and app (`apps/app`). The TypeScript SDK (`sdks/ts`) may reuse it later.
- Stack: TypeScript (strict, ESM), types generated by `openapi-typescript`, requests made by `openapi-fetch` (ADR-010). Consumers import the TypeScript source directly (`exports` points at `src/index.ts`); there is no build step, because Nuxt and Vite compile workspace TypeScript themselves.

## Rules for this package
- Packages are not deployed or versioned on their own; they ship inside the apps that use them.
- A change here affects every consumer. Run the checks of every app listed under "Used by" (README [Commands](../../README.md#commands) table), not just this package's.
- Breaking changes (renamed or removed exports, changed shapes) must update every consumer in the same PR, or be made additive first. API contracts also follow the compatibility rules in docs/TECHNICAL.md, because released mobile and desktop apps keep using old versions.
- Never import from an app. Never put secrets or environment-specific values here.
- Generated files: `src/generated/schema.ts`, generated from `openapi/openapi.json` by `pnpm --filter api-client-ts generate`; never edit it by hand. Regenerate and commit it in the same PR as the spec change. `pnpm --filter api-client-ts check:generated` (also run by this package's `test`) fails when it is out of date.
- The only hand-written code is `src/index.ts` (the `createApiClient({ baseUrl })` factory and convenience type aliases) and its tests. Never hand-write request or response shapes; take them from `paths` and `components`.
- No auth, retries or app logic here: the configured client and auth handling live in `packages/ui` (docs/TECHNICAL.md, ui `client` module). The code makes no SSR or browser assumptions; pass a custom `fetch` where a platform needs one.
- TypeScript is pinned to 5.x here because `openapi-typescript` 7 uses the TypeScript 5 compiler API (the `typescript` 7 package does not provide it).

## Commands
Run from the repo root: `pnpm --filter api-client-ts generate`, `pnpm --filter api-client-ts check:generated`, `pnpm --filter api-client-ts typecheck`, `pnpm --filter api-client-ts test`.
