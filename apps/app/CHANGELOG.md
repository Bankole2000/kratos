## [Unreleased]
### Added
- Desktop and mobile shell: Vue 3 and Vite inside Tauri 2, with one "Platform Core" window that shows the shared layout and status screen from `packages/ui`.
- The api address comes from `VITE_API_BASE_URL` (default `http://127.0.0.1:18080`, see `.env.example`).
- Tauri capabilities limited to the core defaults (no shell, file system or HTTP plugin) and a Content Security Policy that lets the app connect only to itself and the api.
- Android project generated by `tauri android init` in `src-tauri/gen/android`.
