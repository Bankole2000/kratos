# AGENTS.md — web

These instructions add to the repository root `AGENTS.md`; they never relax it. Read the root file first.

## What this app is
- Purpose: the Platform Core dashboard on the web, server-side rendered (OD-005, ADR-006).
- Kind: web client
- Stack: Nuxt 4 (SSR), Vue 3, Vuetify 4, TypeScript. Details in docs/TECHNICAL.md, Components.
- Depends on: `packages/ui` (screens, components, theme, the configured api client) and, through it, `packages/api-client-ts` and the api (`apps/api`).

## Commands
Use this app's row in the README [Commands](../../README.md#commands) table. Run them from the repo root with a filter, e.g. `pnpm --filter web dev` (http://localhost:13000), `pnpm --filter web test`, `pnpm --filter web typecheck`, `pnpm --filter web build`. There is no app-specific linter yet; Prettier runs from the root (`pnpm lint`).

## Rules for this app
- Configuration: every variable in `.env.example` ships to users and is public; never put secrets here. The only setting is `NUXT_PUBLIC_API_BASE_URL` (runtime config `public.apiBaseUrl`, default `http://127.0.0.1:18080`).
- Only routing (`app/pages/`), layouts (`app/layouts/`, `app/app.vue`), Nuxt plugins (`app/plugins/`) and config live here. Screens, components, composables, theme tokens and the api client live in `packages/ui` (principles 18 and 19); import them from `ui`, never write them here.
- Anything Nuxt-specific (auto-imports, `useRuntimeConfig`, SSR handling) stays in this app; `ui` makes no SSR assumptions.
- `app/plugins/ui.ts` installs `ui` with `createPlatformUi({ apiBaseUrl, ssr: true })`. Vuetify and `ui` are compiled by Nuxt (`build.transpile` and `vite.ssr.noExternal` in `nuxt.config.ts`); keep both entries when adding packages that ship `.vue` or CSS source.
- Directories not to edit by hand: `.nuxt/` and `.output/` (generated by Nuxt, gitignored).
- Local dev runs on port 13000. The api allows this origin through CORS (TASK-015); never add a proxy or disable web security to get past CORS.
